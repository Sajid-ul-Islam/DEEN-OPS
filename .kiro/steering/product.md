# DEEN OPS Terminal

AI-assisted operations workspace for WooCommerce, Pathao courier, inventory management, and reporting workflows.

## Summary

DEEN OPS is a Streamlit-based operational dashboard that provides:

- **Live Dashboard**: Real-time sales analytics, KPIs, and ML forecasting from WooCommerce data
- **Pathao Processor**: Courier order creation and management with address parsing
- **Inventory Distribution**: Stock allocation across multiple warehouses with fuzzy matching
- **WhatsApp Messaging**: Order status updates and customer communication
- **Sales Ingestion**: Manual Excel/CSV data upload and processing
- **Stock Analytics**: Historical inventory tracking and snapshot comparison
- **Delivery Parser**: Fuzzy text matching for delivery address standardization
- **Data Pilot**: Multi-provider AI assistant (OpenRouter, Gemini, Groq, Ollama, Hugging Face)

The application uses Google OIDC for authentication and supports runtime configuration validation for all integrations.
